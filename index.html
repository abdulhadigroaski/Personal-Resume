Expense Tracker

A console-based Java application for recording and reviewing personal expenses. Expenses are saved to a file and loaded again when the program starts.

What it does

  • Adds expenses with a description, category, amount and date
  • Displays and deletes recorded expenses
  • Shows the total and the number of expenses
  • Summarises spending by category using a HashMap
  • Handles invalid input and file errors with exception handling

Concepts demonstrated

  • Java
  • OOP
  • ArrayList
  • HashMap
  • File handling
  • Exception handling
  • Java Date and Time API

Student Management System

A console-based Java application for managing students, courses and related academic information. It was built to practise object-oriented design and is meant as a foundation for later versions.

What it does

  • Manages curriculum, semesters and courses
  • Manages batches and students
  • Sets up course offerings with teachers
  • Supports add, remove, search and display operations
  • Validates input and handles exceptions

Concepts demonstrated

  • Java
  • OOP
  • Object composition
  • ArrayList
  • Exception handling
  • Java Time API

Data is stored in memory only, so it is lost when the program closes.
